Fundamental Concepts of Web Technology

1. Internet Overview

The Internet is a worldwide network of interconnected computers and devices used to communicate and share information.

Computer

2. Fundamental Computer Network Concepts

IP Address

Identifies a device on a network.

Protocol

Rules used for communication.

Router

Forwards data between networks.

Packet

Small unit of transmitted data.

3. URL and its Structure

URL stands for Uniform Resource Locator.

https://www.example.com/products/index.html

https – protocol | example.com – domain | /products/index.html – path

4. Domain Name

A domain name is a human-readable address used to access a website.

www.example.com

7. Client-side vs Server-side Scripting

Client-side

  • Runs in the browser.
  • Handles webpage interaction.
  • JavaScript is commonly used.

Server-side

  • Runs on the web server.
  • Processes requests and data.
  • Examples: PHP, Python and Java.
